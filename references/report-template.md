# Report template (8 core metrics)

Default Chinese. Every section: **结论 | 状态(hypothesis/confirmed/refuted/inconclusive) | 证据(jadx/IDA/动态) | 缺口探针**.

## 0. 样本与分析路径

- 包名、版本、渠道、引擎、壳
- 材料：APK / jadx 路径 / so 列表
- **工具路径：**
  - [ ] jadx-mcp 已完成必查清单
  - [ ] native 门闸：是/否；若是，ida-pro-mcp / idalib-mcp 打开的 so
  - [ ] 设备：有/无；若有，clean 最小动态集是否完成（强制）
- 证据档位目标：L1 静态 / L2 行为 / L3 配置明文

## 1. 广告请求结构

|---|---|---|---|---|---|---|

## 2. 广告策略

### 2.1 展示策略

何时 load/show、预加载、bid vs 串行、兜底、实际胜出 DSP。

### 2.2 点击策略

点击是否发奖、伪关闭/CTA 改写、落地优先级（商店/hap/deeplink/H5）。

### 2.3 频控策略

日 cap、间隔、关卡、isClosed、timeout、服务端关位。未知必须写探针（Unity/IDA/长测）。
